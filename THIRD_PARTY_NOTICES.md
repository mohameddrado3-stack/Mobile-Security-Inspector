## PRoot — static ARM64 runtime

MS Terminal bundles the upstream static PRoot executable as an Android-extracted native-library file:

- Component: PRoot 5.3.0, upstream static AArch64 build.
- Source tag: https://github.com/proot-me/proot/tree/v5.3.0
- Release binary: https://github.com/proot-me/proot/releases/download/v5.3.0/proot-v5.3.0-aarch64-static
- Packaged APK filename: `lib/arm64-v8a/libproot-static.so`
- SHA-256: `fa10b1a7818c2f5b1dcb5834450570c368c9ecf66d31521509621b95c4538a45`
- License: GNU GPL-2.0-only. Full license text is included at `app/src/main/assets/licenses/GPL-2.0.txt`.

The PRoot loader is shipped as `libproot-static-loader.so` and is an unmodified copy of the loader ELF embedded in the same PRoot 5.3.0 release binary. It is pinned by SHA-256:
`51c3427b112edc70d1979b48209c41f332616758138de3be659cc79e50436450`.

The loader file is obtained from the public NEXTERM repository at a fixed commit. NEXTERM's published third-party notice documents the loader's origin as an unchanged extraction from the upstream PRoot 5.3.0 executable:
https://github.com/Dreamucxe/NEXTERM/blob/c20ab5d276f601f4e91e5d58683f5ea81c8af8b4/THIRD_PARTY_NOTICES.md

The build downloads both files from the pinned upstream/mirror locations and verifies the hashes before packaging. The PRoot binary is executed as a separate process; MSI does not link against or modify its code.

Corresponding source code:
https://github.com/proot-me/proot/tree/v5.3.0
