# Mobile Security Inspector (MSI)

تطبيق Android محلي لمراجعة **مؤشرات** أمان التطبيقات المثبتة. الفرع التطويري الحالي: **v0.6.0**. هذه نسخة تطوير ومراجعة وليست إصدار إنتاج معتمدًا.

## ما تم بناؤه في v0.6.0

- رفع compileSdk وtargetSdk إلى API 36.
- إعداد Release مع R8 وتقليص الموارد، مع إبقاء Debug منفصلًا.
- فحوص CI لرفض INTERNET وdebuggable في Release وPreviewActivity غير المقصودة، والتحقق من مخرجات R8 وSHA-256.
- Adaptive launcher icon مع طبقة monochrome، وSplashScreen، واسم مختصر MSI، وثلاثة اختصارات ثابتة.
- لوحة ألوان MSI داكنة، وثيم فاتح وAMOLED، وDynamic Color اختياري.
- مؤشر انتباه يشرح قاعدة الحساب، ومقاييس رئيسية قابلة للنقر، وتقدم فحص محدد.
- شبكة 12 فئة صلاحية؛ كل فئة تعرض التطبيقات التي طلبتها والتطبيقات التي مُنحت لها.
- فرز التطبيقات حسب المؤشرات أو تاريخ التثبيت الفعلي أو الاسم، وتجميع حسب مصدر التثبيت، ومقارنة تفصيلية لفروق الصلاحيات المطلوبة والممنوحة وبصمات التوقيع عند توفرها.
- إجراءات السحب على صف التطبيق لنسخ اسم الحزمة أو فتح إعداداته، والضغط المطوّل لنسخ الحزمة أو مشاركة ملخص مؤشرات التطبيق بعد اختيار المستخدم.
- بيانات تطبيق إضافية: targetSdk، وتاريخ التثبيت والتحديث، وتصنيف Android، وبصمة SHA-256 لشهادة التوقيع عند توفرها.
- سجل محلي يحتفظ بآخر 50 فحصًا ولقطات معلومات التطبيقات الجديدة، ومقارنة بين فحصين ورسم اتجاه المؤشرات مع تمييز الفحوص التي كان VPN نشطًا خلالها.
- تقرير كامل غير مقصوص بصيغ TXT وCSV وJSON وPDF، لا يُشارك إلا باختيار المستخدم.
- لوحة صحة جهاز للقراءة فقط: Security Patch، قفل الشاشة، تشفير التخزين، ADB وخيارات المطور، مع فتح صفحة إعدادات Android المناسبة عند النقر.
- Glance widget يعرض آخر فحص وعدّادات مختصرة ويوفر اختصار بدء الفحص.
- فحص محلي دوري اختياري كل 24 ساعة باستخدام WorkManager، مع إشعار عند تغيّر المؤشرات وطلب إذن الإشعارات بعد التفعيل فقط. يتوقف الـWorker إذا ألغى المستخدم موافقته.
- قوائم موثوق/تجاهل محلية، وUsage Access اختياري مغلق افتراضيًا، مع الإشارة إلى بيانات الاستخدام المعروفة فقط.
- سحب لتحديث الفحص من الشاشة الرئيسية، وإجراءات سريعة من قائمة التطبيق.
- Onboarding خصوصية بثلاث خطوات.
- Previews في الكود للشاشات الرئيسية والتطبيقات والصلاحيات والسجل والأدوات، وتنقل تكيفي يستند إلى Material3 WindowSizeClass، وتزامن ألوان أشرطة النظام مع الثيم النشط.

## قواعد المؤشرات

لا توجد درجة خطر رقمية ولا تصنيف malware.

- «يحتاج انتباه» يعني رصد خدمة Accessibility مفعّلة أو تطبيق Device Admin نشط.
- «يحتاج مراجعة» يعني وجود طلب إعداد خاص لا يثبت أن الإعداد مفعّل.
- «هادئ» يعني عدم رصد المؤشرات المحددة ضمن البيانات المتاحة، ولا يعني ضمان سلامة التطبيق.
- الصلاحيات الحساسة العادية لا ترفع مؤشر الانتباه وحدها؛ قد تكون لازمة لوظيفة التطبيق.
- نتيجة MSI لا تثبت أن التطبيق ضار ولا تكشف الملفات الخاصة أو السلوك الداخلي الكامل.

## الخصوصية

- لا تُعلن نسخة التطبيق صلاحية INTERNET ولا تحتوي على SDK تحليلات أو تتبع مقصود.
- ACCESS_NETWORK_STATE مستخدمة فقط لقراءة حالة VPN على مستوى الجهاز.
- فحص التطبيقات والسجل والتقارير تُعالج محليًا. إنشاء الملف ومشاركته لا يحدث إلا بعد اختيار المستخدم.
- FileProvider يتيح قراءة ملف التقرير مؤقتًا للتطبيق الذي يختاره المستخدم.
- MSI لا يمنح أو يسحب صلاحية تطبيق آخر؛ يفتح صفحات إعدادات Android ويترك القرار للمستخدم.
- القفل لا يخزن رمز PIN أو بيانات البصمة؛ Android يتولى التحقق.

## حدود معروفة ومهام لاحقة

تغطي هذه الدفعة وظائف كثيرة من قائمة المنتج، لكنها ليست اعتمادًا نهائيًا. ما زال مطلوبًا:
- ترجمة كاملة إلى الإنجليزية؛ النصوص الأساسية في الواجهات لا تزال في معظمها مكتوبة بالعربية مباشرة.
- خيار موحّد لتبديل شكل الأرقام العربية/اللاتينية.
- تضمين خط عربي مرخّص داخل التطبيق ومراجعته عند تكبير الخط حتى 200%.
- Shared-element transitions، وحالات Skeleton/Loading/Error مكتملة، واحترام تقليل الحركة على جميع الشاشات، وPull-to-refresh حيث يكون منطقيًا خارج الرئيسية.
- استكمال contentDescription وTalkBack واختبارات الوصول لكل عناصر التحكم والإيماءات والرسوم.
- استكمال قياس نافذة Foldable وتغيّرات وضع الطي؛ يوجد حاليًا تكيّف Material3 حسب فئات عرض النافذة وليس تحققًا فعليًا لكل أوضاع الأجهزة القابلة للطي.
- اختبارات Compose UI واختبارات ترحيل قاعدة البيانات وقياسات صحة الجهاز والتنبيهات.
- Render فعلي لكل Preview ومراجعة لقطات الشاشات على أحجام مختلفة. وجود Preview في المصدر لا يعني أنه تم عرض اللقطة وفحصها.
- اختبار Android 8 إلى Android 16، والقفل، والاختصارات، والودجت، والفحص الدوري، وUsage Access، وTalkBack، وRTL وتكبير الخط على محاكي/جهاز فعلي.

السجلات التي أُنشئت في v0.5.0 كانت تحفظ الأعداد فقط. ترقية قاعدة البيانات لا تستطيع استعادة أسماء التطبيقات أو تفاصيلها القديمة؛ لذلك المقارنة التفصيلية تبدأ من أول فحص بعد ترقية v0.6.0.

## البناء والإصدار

GitHub Actions يشغّل Unit Tests، ثم يبني Debug APK وRelease APK مع R8، ويتحقق من targetSdk وdebuggable وغياب INTERNET وPreviewActivity ومكوّنات exported غير المتوقعة وDebugProbes، ويتحقق من mapping.txt ويولد checksums ويعرض أحجام APK. Release الناتج في CI **غير موقّع** عمدًا. يلزم إعداد مفتاح توقيع إنتاجي في GitHub Secrets خارج المستودع قبل توزيع Release.

يخضع QUERY_ALL_PACKAGES لمراجعة وسياسات Google Play. يلزم كذلك اختبار Android 8 إلى Android 16، والقفل، والاختصارات، وTalkBack، والـRTL وتكبير الخط على أجهزة فعلية قبل الاعتماد.
