# Mobile Security Inspector

أداة أندرويد أولية لجمع قائمة التطبيقات المثبتة محليًا وعرض اسم التطبيق ومعرّف الحزمة وما إذا كان النظام يصنّفه كتطبيق نظام.

## الحالة الحالية
- إصدار تجريبي 0.1.0.
- لا يحذف التطبيقات ولا يغيّر إعدادات الجهاز.
- لا يرسل قائمة التطبيقات إلى خادم.
- لا يدّعي اكتشاف البرمجيات الخبيثة؛ التصنيف الحالي وصفي فقط.

## بناء APK
من GitHub افتح تبويب Actions، ثم اختر **Build Android APK** وشغّل **Run workflow**. بعد نجاح التشغيل نزّل artifact باسم `mobile-security-inspector-debug`.

## ملاحظة الخصوصية
يستخدم الإصدار الأول صلاحية `QUERY_ALL_PACKAGES` لعرض قائمة التطبيقات على الجهاز. هذه الصلاحية تخضع لقيود ومراجعة Google Play؛ لا تنشر التطبيق على المتجر قبل مراجعة السياسة وتقليل نطاق الرؤية إن أمكن.
