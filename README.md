# Mobile Security Inspector

تطبيق Android محلي لمراجعة مؤشرات أمان التطبيقات المثبتة. الإصدار التطويري الحالي: **0.5.0**.

## ما يتضمنه الإصدار 0.5.0

- واجهة Jetpack Compose بخمس وجهات: الرئيسية، التطبيقات، الصلاحيات، السجل، ومركز التحكم.
- فصل الفحص عن الواجهة من خلال AppScanner وAppAuditRepository.
- عرض أيقونات التطبيقات وأسمائها وأسماء الحزم والإصدارات ومصدر التثبيت المتاح.
- البحث بالاسم أو اسم الحزمة، وفلاتر للتطبيقات المثبتة وتطبيقات النظام وإعدادات الوصول والصلاحيات الحساسة.
- تحليل الصلاحيات الحساسة المطلوبة والممنوحة كلما كانت المعلومات متاحة.
- رصد خدمات Accessibility المفعّلة وتطبيقات Device Admin النشطة.
- رصد بعض طلبات إعدادات الوصول الخاصة مع توضيح أن الطلب لا يثبت أن الإعداد مفعّل.
- مراجعة فئات الصلاحيات في مركز مستقل.
- قراءة حالة VPN على مستوى الجهاز مع توضيح أنها لا تحدد التطبيق الذي أنشأ الاتصال.
- سجل SQLite محلي يحتفظ بملخص آخر 50 فحصًا، مع مقارنة عدد التطبيقات بين الفحوصات.
- تصدير تقرير نصي بعد موافقة المستخدم واختياره تطبيق المشاركة.
- اختصارات تفتح صفحات إعدادات Android الرسمية.
- قفل اختياري للتطبيق يعتمد على BiometricPrompt والبصمة القوية أو قفل شاشة الجهاز عندما يدعمه إصدار Android.
- تشغيل الفحص خارج خيط الواجهة، والحفاظ على النتائج السابقة عند فشل الفحص الجديد.

## طريقة التقييم

لا توجد درجة خطر رقمية ولا تصنيف malware في هذا الإصدار.

- إعداد وصول خاص نشط: يظهر عند رصد خدمة Accessibility مفعّلة أو تطبيق Device Admin نشط.
- إعداد وصول خاص مطلوب: يعني أن التطبيق أعلن عن طلب إعداد خاص، ولا يثبت أن الصلاحية ممنوحة.
- الصلاحيات الحساسة الممنوحة تُعرض منفصلة؛ فقد تكون ضرورية لوظيفة التطبيق الطبيعية.
- الصلاحيات المطلوبة وغير الممنوحة لا تعامل كأنها مستخدمة.
- مصدر التثبيت غير المعروف وحده لا يرفع تحذيرًا.
- هذه المؤشرات لا تثبت أن التطبيق ضار ولا تكشف الملفات الخاصة أو سلوكه الداخلي.

## الخصوصية والتحكم في الوصول

- فحص التطبيقات وسجل الملخصات يتمان محليًا على الجهاز.
- سجل الفحص يحتفظ بأعداد ووقت الفحص وحالة VPN، ولا يخزن تفاصيل التطبيقات في قاعدة التاريخ.
- لا يتطلب التطبيق صلاحية الإنترنت لإجراء الفحص الحالي.
- قفل MSI لا يخزن رمز PIN أو بيانات البصمة؛ Android يتولى التحقق.
- تغيير صلاحيات التطبيقات الأخرى يتم من صفحات إعدادات Android وبموافقة المستخدم.
- مشاركة التقرير إجراء يدوي ولا تحدث تلقائيًا.

## حدود Android

- التطبيق العادي لا يستطيع منح أو سحب صلاحيات تطبيق آخر بصمت، أو فرض إيقافه، أو حذفه.
- Android لا يوفر واجهة عامة لتطبيق عادي تكشف كل التحديثات المتاحة لكل التطبيقات. المتجر الأصلي هو المرجع لمعرفة التحديث.
- حالة VPN تخص الجهاز كله ولا تحدد التطبيق الذي أنشأ الاتصال.
- بعض إعدادات الوصول الخاصة لا يمكن التأكد من حالتها لكل تطبيق عبر واجهات Android العامة؛ لذلك نعرض الطلب بصفته طلبًا فقط.
- استخدام QUERY_ALL_PACKAGES يخضع لسياسات Google Play ويحتاج مبررًا ومراجعة عند النشر.

## البناء والاختبار

GitHub Actions يشغّل اختبارات Unit Tests ثم يبني Debug APK ويتحقق من SHA-256 قبل رفع Artifact باسم **mobile-security-inspector-v0.5.0**.

الاختبارات الحالية تغطي البحث والفلاتر وتجميع الصلاحيات وملخص الفحص. اختبارات قاعدة البيانات وواجهة Compose واختبار القفل الحيوي على أجهزة فعلية ما زالت مطلوبة قبل إصدار إنتاجي.

## حالة الإصدار

هذه نسخة Debug للاختبار وليست إصدار Release إنتاجيًا موقّعًا بمفتاح ثابت. لم يتم اعتمادها للنشر النهائي قبل مراجعة سياسات QUERY_ALL_PACKAGES، واختبار Android الفعلي، وإعداد توقيع Release ثابت.
