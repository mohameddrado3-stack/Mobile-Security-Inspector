# Mobile Security Inspector

تطبيق Android محلي لمراجعة إعدادات وصلاحيات التطبيقات. الإصدار التطويري الحالي: 0.3.0.

## وظائف الإصدار 0.3.0
- عرض التطبيقات التي يسمح Android للتطبيق برؤيتها.
- قراءة الصلاحيات الحساسة المطلوبة والممنوحة عندما تكون متاحة.
- رصد خدمات Accessibility المفعّلة وتطبيقات Device Admin النشطة.
- عرض مصدر التثبيت وإصدار كل تطبيق.
- فتح معلومات التطبيق وإعدادات صلاحياته وإشعاراته من صفحات Android الرسمية.
- فتح التطبيق، أو صفحة Google Play عند معرفة مصدر التثبيت.
- قائمة لمراجعة التطبيقات وإصداراتها وفتح المتجر الأصلي لمراجعة التحديث.
- تنقل بين الرئيسية والتطبيقات والتحديثات وأدوات إعدادات النظام.
- تنفيذ الفحص على عامل خلفي مع تخزين مؤقت لبيانات تعريف الصلاحيات أثناء الفحص.
- لا تُرسل بيانات التطبيقات أو نتائج الفحص إلى خادم.

## كيف يقرر التطبيق ما الذي يحتاج مراجعة؟
لا توجد درجة خطر ولا تصنيف malware في هذا الإصدار.
- يظهر التطبيق ضمن مرشح **إعدادات الوصول الخاصة** فقط إذا رُصدت له خدمة Accessibility مفعّلة أو كان مفعّلًا كمسؤول جهاز (Device Admin).
- الصلاحيات الحساسة الممنوحة، مثل الكاميرا أو الموقع أو جهات الاتصال، تُعرض كمعلومات منفصلة ولا ترفع تصنيف التطبيق تلقائيًا؛ فقد تكون مطلوبة لوظيفته الطبيعية.
- الصلاحيات المطلوبة وغير الممنوحة تُذكر بوضوح ولا تُعامل كأنها صلاحيات مستخدمة.
- مصدر التثبيت غير المعروف وحده لا يرفع أي تحذير.
- هذه المؤشرات لا تثبت أن التطبيق ضار ولا تكشف الملفات الخاصة داخله.

## حدود Android
- التطبيق العادي لا يستطيع منح أو سحب صلاحيات تطبيق آخر بصمت، أو فرض إيقافه، أو حذفه. يمكنه فتح صفحات إعدادات Android ليقرر المستخدم.
- Android لا يوفر واجهة عامة لتطبيق عادي تكشف كل التحديثات المتاحة لكل التطبيقات. المتجر الأصلي هو المرجع لمعرفة التحديث وتثبيته.
- حالة VPN تخص الجهاز كله ولا تحدد التطبيق الذي أنشأ الاتصال.
- استخدام QUERY_ALL_PACKAGES يخضع لسياسات Google Play ويحتاج مبررًا ومراجعة عند النشر.

## الخصوصية والصلاحيات
- QUERY_ALL_PACKAGES: قراءة قائمة التطبيقات المرئية لغرض الفحص.
- ACCESS_NETWORK_STATE: قراءة حالة VPN على مستوى الجهاز.
- لا يطلب التطبيق صلاحيات Accessibility أو Device Admin لنفسه.
- لا يحذف التطبيقات ولا يعطّلها ولا يغيّر إعدادات الجهاز دون تدخل المستخدم.

## البناء
Workflow: **Build Android APK**. بعد نجاح البناء، نزّل Artifact باسم **mobile-security-inspector-v0.3.0**. يحتوي على APK وملف SHA256SUMS.txt.

## Play Protect
لا يمكن للتطبيق إخفاء نفسه من Play Protect أو تعطيل تحذيراته. التحذير بأن التطبيق غير معروف يختلف عن تصنيفه كضار. يجب فحص أي تحذير محدد، واستخدام توقيع Release ثابت وتقليل الأذونات غير الضرورية قبل النشر.

## حالة الإصدار
نسخة Debug للاختبار، وليست إصدار Release إنتاجيًا موقّعًا بمفتاح ثابت. لا تُعتبر جاهزة للنشر قبل مراجعة الصلاحيات والاختبار على أجهزة فعلية وإعداد توقيع Release.
