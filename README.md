# Mobile Security Inspector

تطبيق Android محلي لمراجعة مؤشرات أمان التطبيقات وإدارة الوصول إلى صفحات إعداداتها. الإصدار التطويري الحالي: 0.3.0.

## الوظائف الموجودة في 0.3.0
- عرض التطبيقات التي يسمح Android للتطبيق برؤيتها.
- فحص الصلاحيات الخطرة المطلوبة والممنوحة عندما تكون متاحة.
- رصد خدمات Accessibility المفعّلة وتطبيقات Device Admin النشطة.
- عرض مصدر التثبيت وإصدار كل تطبيق.
- فتح معلومات التطبيق وإعدادات صلاحياته من صفحة Android الرسمية.
- فتح إعدادات إشعارات التطبيق، أو تشغيله، أو فتح صفحته على Google Play عندما يكون المصدر معروفًا.
- قائمة منفصلة لمراجعة التحديثات؛ تعرض الإصدار الحالي وتفتح صفحة المتجر ليقرر المتجر ما إذا كان هناك تحديث.
- تنقل بين الرئيسية والتطبيقات والتحديثات وأدوات إعدادات النظام.
- تنفيذ الفحص على عامل خلفي، وتخزين نتيجة الصلاحيات الخطرة مؤقتًا أثناء الفحص لتقليل العمل المتكرر.
- لا يرسل بيانات التطبيقات أو نتائج الفحص إلى خادم.

## حدود Android المهمة
- لا يمكن للتطبيق العادي منح أو سحب صلاحيات تطبيق آخر بصمت، أو فرض إيقافه، أو حذفه. يمكنه فتح صفحات إعدادات Android ليقرر المستخدم.
- Android لا يوفر لتطبيق عادي واجهة عامة لمعرفة كل التحديثات المتاحة لكل التطبيقات. المتجر الأصلي هو مصدر التحديث؛ لذلك زر المتجر لا يعني أن تحديثًا متاح بالفعل.
- لا يستطيع التطبيق فحص الملفات الخاصة داخل تطبيقات أخرى أو إثبات وجود برمجية خبيثة.
- صلاحيات الكاميرا والموقع وغيرها قد تكون طبيعية حسب وظيفة التطبيق. النتائج مؤشرات للمراجعة وليست درجات لاحتمال وجود malware.
- حالة VPN تخص الجهاز كله ولا تحدد التطبيق الذي أنشأ الاتصال.
- استخدام QUERY_ALL_PACKAGES مبرر فقط عندما تكون رؤية التطبيقات جزءًا أساسيًا من وظيفة الأمان، ويظل خاضعًا لمراجعة Google Play وسياساته.
- النسخة الحالية Debug APK للاختبار وليست إصدار نشر إنتاجيًّا موقّعًا بمفتاح Release ثابت.

## الصلاحيات والخصوصية
- QUERY_ALL_PACKAGES: قراءة قائمة التطبيقات المرئية لغرض فحصها.
- ACCESS_NETWORK_STATE: قراءة حالة اتصال VPN النشط على مستوى الجهاز.
- لا يطلب التطبيق صلاحيات Accessibility أو Device Admin لنفسه.
- لا يحذف التطبيقات ولا يعطّلها ولا يغيّر إعدادات الجهاز دون تدخل المستخدم.

## البناء
Workflow: **Build Android APK**. بعد نجاح البناء، نزّل Artifact باسم **mobile-security-inspector-v0.3.0**. يحتوي على APK وملف SHA256SUMS.txt.

## تنبيه Play Protect
لا يمكن للتطبيق إخفاء نفسه من Play Protect أو تعطيل تحذيراته. التحذير بأن التطبيق غير معروف يختلف عن تصنيفه كضار. يجب فحص أي تحذير محدد، واستخدام توقيع Release ثابت وتقليل الأذونات غير الضرورية قبل النشر.
