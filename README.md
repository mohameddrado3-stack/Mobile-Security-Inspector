# Mobile Security Inspector

أداة أندرويد محلية لمراجعة مؤشرات أمان التطبيقات المثبتة. الإصدار الحالي 0.2.0.

## حدود مهمة
هذه الأداة ليست مضاد فيروسات شاملًا ولا تستطيع فحص الملفات الخاصة داخل التطبيقات الأخرى أو إثبات وجود برمجية خبيثة. الصلاحيات الحساسة وخدمات Accessibility وDevice Admin ومصدر التثبيت قد تكون مشروعة؛ لذلك النتائج مؤشرات سياقية وليست اتهامات. حالة VPN تخص الجهاز كله ولا تحدد التطبيق الذي أنشأ الاتصال.

## الخصوصية والصلاحيات
- الفحص محلي ولا يتطلب حسابًا أو خادمًا.
- لا يحذف التطبيقات ولا يعطّلها ولا يغيّر إعدادات الأمان.
- يستخدم QUERY_ALL_PACKAGES لرؤية التطبيقات، وهي صلاحية مقيدة في Google Play وتحتاج مراجعة سياسة المتجر قبل النشر.
- يستخدم ACCESS_NETWORK_STATE لقراءة حالة اتصال VPN النشط على الجهاز.

## بناء APK
Workflow: **Build Android APK**. بعد نجاح البناء، نزّل artifact باسم **mobile-security-inspector-v0.2.0** من صفحة Actions. يحتوي على APK وملف SHA256SUMS.txt.
